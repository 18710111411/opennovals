- 方式：封印沉睡·百年重生（主动布局）
- 时间：封印 100 年，刚刚破除
- 仇人：叶红鱼（道侣）、赵无极（挚友）→ 现为化神/炼虚期大佬
- 复仇线：暗中布局，等实力足够再出手

### 系统设定

**天机系统**
- 每日提示：3 条（信息优势）
- 积分获取：事件驱动（社死/布局/女主好感）

- 定位：辅助工具，不是依赖

## 🎯 写作原则

### 主角行为准则
1. 不主动装逼（没必要）
2. 不被挑衅（无视蝼蚁）
3. 不暴露实力（暗中布局）
4. 有仇必报（等时机成熟）

### 节奏控制
- 前三章精写（每章 3500+ 字）
- 每 5 章一个小高潮
- 每 20 章一个大高潮
- 复仇线只在关键节点提醒

### 女主尺度
- 允许发生关系，含蓄描写
- 重点在情感和氛围
- 用"留白"让读者想象
- 每位女主 3-4 次关键进展

### 社死情节
- 每 10 章 1-2 次
- 不伤害主角尊严
- 最终能反转/解释
- 主角淡然处之（不当回事）
