## 一、核心概念

### 1.1 法术卷轴 vs 心法

| 类型 | 定义 | 使用方式 | 消耗 | 示例 |
|------|------|----------|------|------|
| **法术卷轴** | 预先封印的法术 | 一次性使用（撕毁卷轴） | 灵石/灵力 | 《火球术卷轴》 |
| **心法** | 修炼的根本法 | 长期修炼（融入体内） | 时间/精力 | 《青阳功》 |

**关系：**
```
心法 = 内力修炼（决定灵力总量和质量）
卷轴 = 招式释放（决定灵力运用方式）

最佳搭配：
  火系心法 + 火系卷轴 = 威力 +20%
  金系心法 + 火系卷轴 = 无加成
  水系心法 + 火系卷轴 = 威力 -20%（相克）
```

### 1.2 元素体系

| 元素类型 | 元素 | 可修炼境界 | 稀有度 |
|----------|------|------------|--------|
| **基础五行** | 金 | 所有境界 | 常见 |
| | 木 | 所有境界 | 常见 |
| | 水 | 所有境界 | 常见 |
| | 火 | 所有境界 | 常见 |
| | 土 | 所有境界 | 常见 |
| **变异元素** | 风（金 + 火） | 筑基+ | 稀有 |
| | 雷（金 + 水） | 筑基+ | 稀有 |
| | 冰（水 + 金） | 筑基+ | 稀有 |
| **高级元素** | 光明 | 金丹+ | 极稀有 |
| | 黑暗 | 金丹+ | 极稀有 |
| **法则元素** | 时间 | 元婴+ | 传说 |
| | 空间 | 元婴+ | 传说 |

**元素相克关系：**
```
金 → 木 → 土 → 水 → 火 → 金（循环相克）

相克方 +20% 伤害，被克方 -20% 伤害
同元素 +10% 伤害（共鸣）
```

| 品阶 | 词条上限 | 威力倍率 | 对应境界 | 获取难度 | 示例 |

| **玄阶** | 3 词条 | 10× | 筑基 - 金丹 | 高 | 《玄阴功》 |
| **黄阶** | 2 词条 | 3× | 炼气 - 筑基 | 中 | 《基础剑法》 |

### 2.2 残卷体系（降级对应）

**残卷定义：** 完整功法的部分章节/残缺版本

| 残卷类型 | 威力 | 词条上限 | 品阶降级 | 示例 |
|----------|------|----------|----------|------|
| **完整卷** | 100% | 正常 | 无降级 | 《青阳剑典》（完整） |
| **上卷** | 70% | -1 词条 | 降 1 阶 | 《青阳剑典·上卷》（地阶→玄阶） |
| **中卷** | 50% | -2 词条 | 降 2 阶 | 《青阳剑典·中卷》（地阶→黄阶） |
| **下卷** | 30% | -2 词条 | 降 2 阶 | 《青阳剑典·下卷》（地阶→黄阶） |
| **残页** | 10% | 1 词条 | 降 3 阶 | 《青阳剑典·残页》（地阶→凡阶） |

**残卷特点：**
- 可修炼，但无法达到完整威力
- 集齐多卷可合成完整卷（威力恢复）
- 残卷价格 = 完整卷 × (威力% ÷ 2)

**示例：**
```
《九天玄火诀》（天阶完整）= 价值 100 万灵石
《九天玄火诀·上卷》（玄阶）= 价值 35 万灵石（70%÷2）
《九天玄火诀·中卷》（黄阶）= 价值 25 万灵石（50%÷2）
《九天玄火诀·残页》（凡阶）= 价值 5 万灵石（10%÷2）
```

## 四、法术卷轴体系

### 4.1 卷轴命名规则

```
命名格式：[前缀] + [元素] + [法术类型] + [品阶后缀]

前缀：
  - 基础：无/小/大
  - 进阶：玄/真/神
  - 顶级：九天/混沌/天帝

元素：
  - 五行：金/木/水/火/土
  - 变异：风/雷/冰
  - 高级：圣光/幽冥
  - 法则：时光/空间

法术类型：
  - 攻击：火球/雷击/冰锥/剑诀
  - 防御：护盾/金钟/罡气
  - 辅助：加速/隐身/治疗
  - 特殊：传送/召唤/封印

品阶后缀：
  - 凡阶：诀/术
  - 黄阶：诀/法
  - 玄阶：功/法
  - 地阶：典/经
  - 天阶：真经/帝诀
```

**示例：**
- 《小火球术卷轴》（凡阶）
- 《青阳火诀卷轴》（黄阶）
- 《玄阳功卷轴》（玄阶）
- 《焚天火典卷轴》（地阶）
- 《九阳真经卷轴》（天阶）

## 六、使用规则

### 6.1 心法修炼规则

| 规则 | 内容 | 违反后果 |
|------|------|----------|
| **境界匹配** | 心法品阶必须≤当前境界可承受 | 超限修炼→经脉受损 |
| **元素匹配** | 灵根必须与心法元素兼容 | 不兼容→无法修炼 |
| **门派限制** | 部分心法仅限门派弟子修炼 | 偷学→被追杀 |
| **残卷限制** | 残卷威力降级，无法突破大境界 | 需集齐完整卷 |
| **心法数量** | 每人最多同时修炼 3 部心法 | 超限→灵力冲突 |

### 6.2 卷轴使用规则

| 规则 | 内容 | 违反后果 |
|------|------|----------|
| **境界匹配** | 卷轴品阶必须≤当前境界 +1 | 超限使用→灵力透支 |
| **元素加成** | 同元素心法 + 同元素卷轴 = 威力 +20% | 无加成 |
| **元素相克** | 相克元素卷轴威力 -20% | 威力降低 |
| **一次性** | 卷轴使用后消失 | 无法重复使用 |
| **灵力消耗** | 使用卷轴消耗对应灵力 | 灵力不足→使用失败 |

### 6.3 主角的特殊规则

| 优势 | 说明 | 效果 |
|------|------|------|
| 词条之眼 | 可看到卷轴/心法真实品阶 | 捡漏（残卷→完整卷） |
| 词条提取 | 可提取卷轴/心法词条 | 无需修炼直接获得能力 |
| 词条融合 | 可融合多心法词条 | 突破心法数量限制 |
| [一式万遍] | 心法修炼速度×800-10000 | 1 天 = 常人 10 年 |
