## 一、仙术核心概念

### 1.1 仙术定义

```
仙术 = 灵力运用技巧 + 法则理解 + 天地共鸣

功法：修炼灵力的根本法（如《青阳功》）
仙术：灵力的具体运用方式（如《青阳剑诀》）

关系：
  功法 = 内力
  仙术 = 招式
```

### 1.2 仙术分类

| 分类 | 说明 | 示例 |
|------|------|------|
| **剑术** | 剑修专用战技 | 《青阳剑诀》《九天玄剑》 |
| **法术** | 五行/阴阳/雷电等 | 《火球术》《雷击术》 |
| **身法** | 移动/闪避/遁术 | 《追风步》《缩地成寸》 |
| **防御术** | 护盾/护体/格挡 | 《护体罡气》《金钟罩》 |
| **辅助术** | 增益/减益/治疗 | 《加速术》《疗伤术》 |
| **秘术** | 爆发类（有副作用） | 《燃血术》《爆灵术》 |
| **阵法** | 多道灵力组合 | 《困灵阵》《杀仙阵》 |
| **符术** | 符箓制作/使用 | 《火球符》《传送符》 |

## 八、词条与仙术的融合

### 8.1 融合规则

```
仙术 = 载体
词条 = 增强模块

融合后：
  威力 = 基础威力 × 词条加成
  消耗 = 基础消耗 ÷ 词条效率
  熟练度 = 练习次数 × 词条加速
```

### 8.2 融合示例

#### 示例 1：《基础剑法》+ [一式万遍]

```
融合前：
  威力：1×
  修炼速度：1×
  词条上限：2

融合后：
  威力：1×（基础不变）
  修炼速度：10000×（每剑=万剑）
  实际战力：1000×（熟练度碾压）
  熟练度：化境（1 天达成）
```

#### 示例 2：《火球术》+ [火焰 +2] + [爆炸 +1]

```
融合前：
  威力：1×
  范围：5 米
  词条上限：2

融合后：
  威力：3×（火焰 +2）
  范围：10 米（爆炸 +1）
  实际战力：5×
```

#### 示例 3：《青阳剑典》+ [剑意雏形] + [灵力倍增]

```
融合前：
  威力：10×
  词条上限：4

融合后：
  威力：10× × 2（剑意雏形）× 1.5（灵力倍增）= 30×
  实际战力：地阶巅峰
```

### 8.3 主角的仙术融合策略

| 阶段 | 策略 | 目标 |
|------|------|------|
