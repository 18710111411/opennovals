## 一、系统核心概念

### 1.1 追踪系统定义

```
追踪系统 = 物品数据库 + 人物数据库 + 状态更新机制

功能：
  - 记录所有物品获取/丢失/升级
  - 记录人物境界/状态/关系变化
  - 关键词触发自动更新
  - 保持一致性检查
```

### 1.2 关键词触发机制

| 关键词类型 | 触发词 | 动作 | 更新对象 |
|------------|--------|------|----------|
| **物品获取** | `#获得物品` | 新增物品记录 | 物品库 + 人物物品栏 |
| **物品丢失** | `#失去物品` | 标记物品状态 | 物品库 |
| **物品升级** | `#升级物品` | 更新物品品阶 | 物品库 |
| **物品损坏** | `#损坏物品` | 更新耐久度 | 物品库 |
| **物品修复** | `#修复物品` | 恢复耐久度 | 物品库 |
| **物品交易** | `#交易物品` | 更新主人 | 物品库 + 人物物品栏 |
| **境界提升** | `#突破境界` | 更新人物境界 | 人物库 |
| **状态变化** | `#状态变化` | 更新人物状态 | 人物库 |
| **关系变化** | `#关系变化` | 更新人物关系 | 人物关系库 |
| **功法学习** | `#学习功法` | 更新人物技能 | 人物技能库 |

## 五、状态更新触发器详解

### 5.1 物品类触发器

#### `#获得物品`

```yaml
触发格式: #获得物品 {物品名} {品阶} {来源} {章节}

示例:
  #获得物品 铁剑 凡器 陆家带走 第 1 章
  #获得物品 储物袋 凡器 青阳宗发放 第 1 章
  #获得物品 火球术卷轴 凡阶 藏经阁购买 第 2 章

动作:
  1. 新增物品记录
  2. 设置主人为当前人物
  3. 记录获取时间和来源
  4. 添加到人物物品栏
```

#### `#失去物品`

```yaml
触发格式: #失去物品 {物品名} {原因} {章节}

示例:
  #失去物品 鬼头刀 战斗损毁 第 1 章
  #失去物品 灵石袋 被劫修抢走 第 1 章（已夺回）
  #失去物品 疗伤丹 使用 第 2 章

动作:
  1. 标记物品状态为"已失去"
  2. 记录失去原因
  3. 从人物物品栏移除
```

#### `#升级物品`

```yaml
触发格式: #升级物品 {物品名} {原品阶}→{新品阶} {升级方式} {章节}

示例:
  #升级物品 铁剑 凡器→灵器 词条融合 第 1 章
  #升级物品 储物袋 凡器→灵器 材料强化 第 30 章

动作:
  1. 更新物品品阶
  2. 增加词条槽位
  3. 记录升级历史
```

#### `#镶嵌词条`

```yaml
触发格式: #镶嵌词条 {物品名} {词条名} {章节}

示例:
  #镶嵌词条 铁剑 [锋利 +2] 第 1 章
  #镶嵌词条 铁剑 [饮血 +1] 第 1 章

动作:
  1. 更新物品词条栏
  2. 占用词条槽位
  3. 记录镶嵌历史
```

### 5.2 人物类触发器

#### `#突破境界`

```yaml
触发格式: #突破境界 {人物名} {原境界}→{新境界} {章节}

示例:

  #突破境界 陆离 炼气 1 层→炼气 2 层 第 1 章

动作:
  1. 更新人物境界
  2. 更新战力基准
  3. 更新寿元
  4. 记录突破时间
```

#### `#状态变化`

```yaml
触发格式: #状态变化 {人物名} {原状态}→{新状态} {原因} {章节}

示例:
  #状态变化 陆离 正常→受伤 劫修攻击 第 1 章
  #状态变化 陆离 受伤→正常 疗伤丹治疗 第 1 章
  #状态变化 刀疤男 正常→死亡 被主角击杀 第 1 章

动作:
  1. 更新人物状态
  2. 记录变化原因
  3. 如死亡则标记时间
```

#### `#关系变化`

```yaml
触发格式: #关系变化 {人物 A} {人物 B} {原关系}→{新关系} {原因} {章节}

示例:
  #关系变化 陆离 王富贵 陌生→盟友 成为室友 第 2 章

  #关系变化 陆离 福伯 主仆→友好 送灵石 第 1 章

  1. 更新人物关系网
  2. 记录变化原因
  3. 影响后续互动
```

#### `#学习功法`

```yaml
触发格式: #学习功法 {人物名} {功法名} {品阶} {熟练度} {章节}

示例:
  #学习功法 陆离 《基础剑法》凡阶 化境 第 1 章
```

## 六、一致性检查

### 6.1 自动检查规则

| 检查类型 | 规则 | 违规示例 |
|----------|------|----------|
| **境界匹配** | 功法品阶≤人物境界 +1 | 炼气期使用地阶功法 ❌ |
| **物品存在** | 使用物品前必须已获得 | 未获得就使用 ❌ |
| **耐久度检查** | 物品耐久>0 才能使用 | 耐久 0 仍使用 ❌ |
| **寿命检查** | 寿命>0 才能存活 | 寿命 0 仍活动 ❌ |
| **关系一致性** | 关系变化有原因 | 无故变敌对 ❌ |
| **位置一致性** | 人物位置合理 | 同时在两地 ❌ |

### 6.2 检查触发时机

```
每次状态更新后:
  1. 检查境界匹配
  2. 检查物品存在
  3. 检查耐久度
  4. 检查寿命
  5. 检查关系一致性
  6. 检查位置一致性

发现违规:
  - 🟡 轻微：警告，建议修改
  - 🟠 中等：必须修改
  - 🔴 严重：阻止更新，必须修复
```
