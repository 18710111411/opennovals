### 6.2 凡人修仙通道

```
凡人 → 测灵根 → 有灵根 → 宗门测试 → 入门 → 外门弟子 → 内门弟子 → 真传弟子

灵根品阶：
  - 天灵根（单属性）：直接真传
  - 地灵根（双属性）：直接内门
  - 上灵根（三属性）：外门
  - 中灵根（四属性）：外门（杂役起步）
  - 下灵根/杂灵根（五属性）：杂役/外门（看背景）

主角灵根：杂灵根（五属性）→ 外门杂役起步
```
