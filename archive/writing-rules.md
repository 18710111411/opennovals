## 一、核心设定规则

### 1.1 金手指设定

| 项目 | 设定 |
|------|------|
| **核心系统** | 词条之眼（看到/提取/融合/赋予） |
| **辅助行为** | 风险投资（投资人才/功法/势力获得返利） |
| **词条等级** | 白→绿→蓝→紫→金→红 |
| **使用限制** | 每日提取次数有限制，随修为提升 |

**规则：** 投资行为是主角的"副业"，不是系统功能，靠眼光赚钱

---

### 1.2 反派与伏笔规则

| 规则 | 说明 | 执行标准 |
|------|------|----------|
| **反派不频繁** | 大反派不要总露面 | 每 50 章出现一次即可 |
| **伏笔不常提** | 埋的伏笔不要总提醒读者 | 埋下后至少 10 章再回收 |
| **小反派轮替** | 每个地图换一批小反派 | 避免审美疲劳 |
| **反派有动机** | 反派作恶要有合理理由 | 不是为坏而坏 |

### 1.3 词条使用规则 ⭐核心

#### 规则 006-提取次数限制（苛刻模式）

```yaml
描述：词条提取每日有次数限制（苛刻模式）
限制：炼气期 1 次/日，筑基期 2 次/日，金丹期 3 次/日
恢复：每日凌晨重置
超限：强行提取会反噬（修为跌落/受伤）
检查：每次提取后计数
拦截：超限则提示"今日提取次数已用尽，强行提取会反噬"
```

#### 规则 009-词条查看限制

```yaml
描述：不能什么词条都能看到，有限制
限制 1：修为高于主角>2 个大境界，无法查看（显示为？？？）
限制 2：有遮蔽类词条的物品/人，无法查看或显示错误
限制 3：每日查看次数有限（炼气期 10 次/日，超过消耗精神力）
超限后果：精神力透支（头痛/眩晕/短暂失明）
例外：与主角有深度绑定的人/物（如王富贵的剑）可查看
```

#### 规则 010-词条查看消耗

```yaml
描述：查看词条消耗精神力/灵力
消耗：
  - 白色词条：微量精神力
  - 绿色词条：少量精神力
  - 蓝色词条：中等精神力
  - 紫色及以上：大量精神力（可能头痛）
恢复：休息/服用恢复精神力的丹药
表现：频繁使用后主角会头痛、眩晕
```

#### 规则 011-修为差查看限制（新增核心规则）

```yaml
描述：无法看到修为高于自己 2 个大境界以上的词条/信息
限制：
  - 炼气期：最高看到筑基期（高 1 阶），元婴期 + 显示???
  - 筑基期：最高看到金丹期（高 1 阶），化神期 + 显示???
  - 金丹期：最高看到元婴期（高 1 阶），炼虚期 + 显示???
例外：
  - 有遮蔽类词条的物品/人，即使修为低也可能无法查看
  - 与主角有深度绑定的人/物（如王富贵的剑）可查看
表现：
  - 高于 2 大境界：显示【？？？】
  - 高于 1 大境界：显示修为，词条模糊
  - 同阶/低阶：正常显示
```

#### 规则 012-美女爽点设计（新增）

```yaml
描述：男频修仙核心爽点之一，多女群像 + 单女主
要求：
  - 每 10 章至少 1 个女性角色登场
  - 女主每 20 章至少出现 1 次
  - 女性角色必须有独立目标/成长线
  - 禁止花瓶化（必须有作用）
爽点类型：
  - 惊艳登场（外貌/气质震撼）
  - 实力认可（女主/女配认可主角实力）
  - 主动示好（地位高的女性对主角特殊对待）
  - 为敌出头（女性角色为主角与他人冲突）
  - 情感进展（关系递进，但不可太快）
禁忌：
  - 禁止无脑倒贴（除非有特殊原因）
  - 禁止花瓶化（必须有独立作用）
  - 禁止后宫（单女主，其他是暧昧/欣赏）
检查：统计女性角色登场频率和质量
```

#### 规则 016-危机设计规则（新增核心）

```yaml
描述：避免主角太顺，增加真正危机感
要求：
  - 每 10 章至少 1 次真正危机（打不过/逃不掉）
  - 每 20 章至少 1 次失去（朋友/宝物/机会）
  - 危机必须有倒计时压力（3 天/7 天等）
  - 危机不能轻松解决（必须付出代价）
危机类型：
  - 实力危机：遇到真正打不过的敌人
  - 信任危机：朋友被威胁/利诱
  - 资源危机：修炼资源被断
  - 时间危机：倒计时压力
检查：统计每 10 章危机次数和类型
```

#### 规则 017-主角弱点规则（新增核心）

```yaml
描述：主角必须有致命弱点，增加代入感
要求：
  - 至少 1 个致命弱点（情绪/身体/关系）
  - 弱点必须被敌人利用过
  - 弱点必须影响过剧情走向
  - 弱点不能轻易克服
弱点类型：
  - 情绪弱点：母亲相关的事会失控
  - 身体弱点：某处旧伤/某种毒素
  - 关系弱点：在乎的人被威胁
  - 能力弱点：某种情况下能力失效
检查：统计弱点出现频率和影响
```

#### 规则 018-短期期待规则（新增核心）

```yaml
描述：必须有 3-5 章内揭晓的强悬念
要求：
  - 每 5 章至少 1 个短期悬念
  - 悬念必须有明确倒计时
  - 悬念揭晓必须有反转
  - 不能无限期拖延
悬念类型：
  - 身份悬念：某人真实身份
  - 目的悬念：某人接近主角的目的
  - 生死悬念：朋友/亲人能否获救
  - 宝物悬念：某宝物能否获得
检查：统计悬念埋设和揭晓时间
```

#### 规则 019-失去情节规则（新增核心）

```yaml
描述：让主角真正失去，增加情感冲击
要求：
  - 每 20 章至少 1 次真正失去
  - 失去必须无法挽回
  - 失去必须影响主角行为
  - 失去必须让读者心痛
失去类型：
  - 失去朋友：为救主角受伤/失踪
  - 失去宝物：辛苦获得的被夺走
  - 失去机会：错过突破/宝物
  - 失去信任：被某人背叛
检查：统计失去情节频率和影响
```

#### 规则 020-寿命代价规则（新增核心）

```yaml
描述：每次使用能力都有代价
代价设定：
  - 查看紫色以上词条：消耗 1 天寿命
  - 提取词条：消耗 10 天寿命
  - 融合词条：消耗 5 天寿命
  - 正常使用：无消耗
当前状态：
  - 陆离剩余寿命：正常人的 80%
  - 已消耗寿命：约 5 年
  - 警告线：剩余 50% 时必须有恢复手段
表现：
  - 每次使用后显示剩余寿命
  - 寿命过低时有警告提示
  - 必须有恢复寿命的途径（极难）
检查：统计寿命消耗和剩余
```

#### 规则 021-爽点对比规则（修改）

```yaml
描述：增加憋屈→爆发的对比
要求：
  - 每 3 章小憋屈→小爆发
  - 每 10 章大憋屈→大爆发
  - 憋屈必须真实（不能假装）
  - 爆发必须爽（碾压/反转）
对比类型：
  - 实力憋屈：遇到打不过的
  - 资源憋屈：被抢/被限制
  - 关系憋屈：被误解/被背叛
  - 时间憋屈：倒计时压力
检查：统计憋屈和爆发比例
```

描述：女主关系必须有不确定性和拉扯

### 1.4 文笔质量规则（新增 v3.1）

#### 规则 023-反流水账规则（新增核心）

```yaml
描述：禁止流水账式写作，必须让读者"感受到"而不仅是"知道"
流水账特征：
  - 只有动作，没有感受
  - 只有对话，没有场景
  - 只有结果，没有过程
  - 只有视觉，没有五感
  - 只有叙述，没有细节
  - 只有主线，没有支线
反流水账要求：
  - 关键动作必须描写过程（不是"拿起剑"，是"握住剑柄，掌心传来凉意"）
  - 对话必须配合动作/环境（不是纯对话，是"说话时手在做什么"）
  - 重要场景必须有氛围（时间/空间/道具/气味）
  - 情绪必须外化（不是"他紧张"，是"指尖发颤/喉咙发干"）
检查：首席编辑逐章检查，流水账段落🔴 必须重写
```

#### 规则 024-五感描写规则（新增核心）

```yaml
描述：每章至少使用 3 种感官描写
感官类型：
  - 视觉：颜色/形状/动作/光影
  - 听觉：声音/音调/节奏/远近
  - 触觉：温度/质感/重量/疼痛
  - 嗅觉：气味/味道/浓淡
  - 味觉：甜/苦/酸/辣/咸（可选）
最低要求：
  - 每章至少 3 种感官
  - 关键场景至少 4 种感官
  - 战斗场景必须包含触觉（疼痛/重量）
检查：统计每章感官类型数量，<3 种🟡 建议修改
```

#### 规则 025-场景细节规则（新增核心）

```yaml
描述：每个场景至少 1 处具体环境/道具细节
场景要素：
  - 时间感：清晨/正午/黄昏/夜晚（光线变化）
  - 空间感：大/小/开阔/压抑（空间描述）
  - 氛围感：紧张/轻松/压抑/温馨（情绪基调）
  - 道具细节：至少 1 个具体物品描写（旧/新/破损/精致）
示例：
  - ❌ "他们来到演武场"
  - ✅ "演武场四周已经围满了人。青石看台被晨露打湿，泛着暗色的光。"
检查：每个场景必须有至少 1 处细节，无细节🟡 建议修改
```

#### 规则 026-对话穿插规则（新增核心）

```yaml
描述：对话不超过 5 轮必须穿插动作/环境/心理描写
对话要求：
  - 连续对话≤5 轮（必须穿插）
  - 每句对话至少有 1 个潜台词
  - 对话配合动作（说话时手在做什么）
  - 古风包装（避免现代口语如"卧槽""牛逼"）
穿插类型：
  - 动作穿插："他说"→"他握住剑柄，指节发白"
  - 环境穿插：插入场景细节（风声/光线/气味）
  - 心理穿插：主角内心活动/判断
  - 观察穿插：主角观察对方的细节
检查：统计连续对话轮数，>5 轮🟡 建议修改
```

#### 规则 027-情绪外化规则（新增核心）

```yaml
描述：不直接说情绪，用肢体/生理反应表现
情绪外化示例：
  - ❌ "他很紧张"
  - ✅ "指尖微微发颤，指甲掐进掌心"
  - ❌ "她生气了"
  - ✅ "她嘴角抿成一条直线，呼吸变得急促"
  - ❌ "他很高兴"
  - ✅ "他眼底闪过一丝光亮，嘴角不自觉地上扬"
生理反应库：
  - 紧张：指尖发颤/喉咙发干/手心出汗/心跳加速
  - 愤怒：嘴角抿直/呼吸急促/指甲掐掌心/青筋暴起
  - 高兴：眼底发光/嘴角上扬/脚步轻快/哼歌
  - 悲伤：眼眶发红/声音哽咽/低头不语/握紧某物
检查：直接说情绪（紧张/生气/高兴）无外化🟡 建议修改
```

## 三、剧情规则

### 3.1 节奏控制

| 章节区间 | 要求 |
|----------|------|
| 每章 | 必须有推进（剧情/人物/世界观） |
| 每 3 章 | 至少 1 个小爽点 |
| 每 10 章 | 至少 1 个中高潮 |
| 每 50 章 | 至少 1 个大高潮 |
| 每 100 章 | 一个大篇章结束 |

---

### 3.2 爽点类型

| 类型 | 说明 | 示例 |
|------|------|------|
| **信息差碾压** | 主角知道别人不知道 | 看出宝物有隐藏词条 |
| **捡漏打脸** | 低价买入被看不起的物品 | 废品实际是神器 |
| **实力碾压** | 同阶无敌 | 越级挑战 |
| **人脉碾压** | 投资的人都在关键时刻帮忙 | "我徒儿是大佬" |
| **财富碾压** | 有钱任性 | 买买买不眨眼 |
| **智商碾压** | 布局坑人 | 反派自己跳坑里 |

---

### 3.3 投资行为融入

**投资作为主角的"副业行为"，不是系统功能：**

| 阶段 | 投资行为 |
|------|----------|
| 前期 | 投资室友/同门（送功法/送丹药） |
| 中期 | 投资散修/小势力（提供资源换人情） |
| 后期 | 投资大宗门/圣地（战略合作） |

**返利机制：** 被投资者变强/成功，主角获得：
- 人情（关键时刻帮忙）
- 分红（灵石/功法/宝物）
- 信息（内部消息）
- 词条（特殊情况下可提取）

**规则：** 投资是"人情投资"，不是系统自动返利

## 四、一致性检查规则

### 4.1 人物一致性检查清单

每次章节发布前检查：

```
□ 主角行为是否符合性格？
□ 逗逼角色是否说了符合人设的话？
□ 女主是否有独立行动（不是主角附庸）？
□ 配角行为是否有背景/动机支撑？
□ 人物关系变更是否有剧情支撑？
□ 人物年龄/修为是否连续？
```

### 4.2 世界观一致性检查清单

```
□ 新出现的词条等级是否符合体系？
□ 修为境界描述是否一致？
□ 地理位置/距离是否合理？
□ 势力关系是否与设定一致？
□ 功法/物品是否有前后矛盾？
```

### 4.3 剧情一致性检查清单

```
□ 是否跳过关键剧情节点？
□ 伏笔是否超期未回收（>50 章）？
□ 爽点密度是否达标？
□ 节奏是否忽快忽慢？
```

## 五、Agent 分工与权限

| Agent | 职责 | 权限 |
|-------|------|------|
| **主编** | 项目统筹、终审、规则更新 | 可修改所有设定 |
| **世界观架构师** | 修炼体系/地理/势力/词条库 | 可添加世界观设定 |
| **剧情规划师** | 大纲/节奏/爽点/伏笔 | 可调整剧情走向 |
| **人物塑造师** | 人物卡/行为审核/对话风格 | 可否决人物行为 |
| **初稿写手** | 章节撰写 | 需在设定范围内写作 |
| **一致性审核员** | 规则检查、冲突标记 | 可驳回不合规章节 |

## 六、工作流程

```
剧情大纲 → 世界观审核 → 人物审核 → 初稿撰写 → 五层检查 → 主编终审 → 发布
    ↓           ↓            ↓          ↓          ↓           ↓        ↓
  剧情师     架构师       塑造师     写手       审核员      主编    平台
```

### 五层检查详解

```
第 1 层：人物一致性检查
  - 行为是否符合性格？
  - 语言是否符合特征？
  - 关系是否连续？

第 2 层：世界观一致性检查
  - 修炼体系是否正确？
  - 词条等级是否合理？
  - 地理/势力是否冲突？

第 3 层：剧情一致性检查
  - 是否跳过关键节点？
  - 伏笔是否超期？
  - 爽点密度是否达标？

第 4 层：语言风格检查
  - 是否符合古风？
  - 黄腔是否隐喻？
  - 逗逼台词是否到位？

第 5 层：商业性检查
  - 是否有断章点？
  - 是否有追读钩子？
  - 是否符合番茄节奏？
```
