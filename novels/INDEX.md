## 🔄 更新流程

### 新章节发布

1. **写作** → 在 `current-novel/chapters/` 创建新文件
2. **自检** → 检查字数、格式、境界
3. **提交** → `git add && git commit -m "📖 完成第 X 章"`
4. **推送** → `git push`
5. **更新索引** → 更新本文件的章节列表
