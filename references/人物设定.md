## 主角：林凡

### 基本信息
| 项目 | 内容 |
|------|------|
| **外表年龄** | 20 岁 |
| **实际年龄** | 约 200 岁（心理年龄） |
| **前世修为** | 元婴初期（阵法师） |
| **今生修为** | 筑基初期（归零重新开始） |
| **身份** | 青云宗外门弟子（表面）/ 重生大能（实际） |

### 性格特征
| 特征 | 描述 | 表现 |
|------|------|------|
| **表面** | 低调、温和、好说话 | 对谁都客气，不摆架子 |
| **内心** | 冷酷、算计、睚眦必报 | 仇记在心里，等时机报复 |
| **处事** | 能忍则忍，该狠则狠 | 小事不计较，大事不含糊 |
| **情感** | 理性大于感性 | 不会被感情冲昏头脑 |

### 行为准则
```
1. 不主动装逼（没必要，低调发展）
2. 不被挑衅（无视蝼蚁，不浪费精力）
3. 不暴露实力（暗中布局，关键时刻再出手）
4. 有仇必报（但等时机成熟，不冲动）
5. 感情随缘（不主动追求，但不拒绝真心）
```

### 金手指
**天机系统**
- 每日提示：3 条（信息优势）
- 积分获取：事件驱动（布局成功/女主好感/偶尔社死）
- 积分用途：功法推演、阵法优化、特殊道具
- 定位：辅助工具，不是依赖

### 经典台词
```
"百年前你们杀我一次，这一世……我会让你们死得更明白。"
"现在不是暴露的时候。"
"蝼蚁的议论，与我何干？"
"好。（表面答应，心里另有打算）"
```
